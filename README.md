# Cyber Threat Intelligence Using Graph Neural Networks

## Project Overview

This project focuses on using Graph Neural Networks (GNNs) for Cyber Threat Intelligence.

The system represents cybersecurity entities such as IP addresses, domains,
network activities, and attacks as a graph. The GNN model learns relationships
between these entities to identify potentially malicious activities.

## Objectives

- Represent cybersecurity data as a graph.
- Apply Graph Neural Networks for threat detection.
- Identify potentially malicious IP addresses and domains.
- Analyze relationships between cybersecurity entities.
- Evaluate the performance of the proposed model.
